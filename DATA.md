# Origem e transformação dos dados

**Human Activity Recognition Using Smartphones**, versão 1.0. Os autores coletaram sinais de 30 voluntários usando um Samsung Galaxy S II na cintura. Os arquivos utilizados vêm de `Inertial Signals/total_acc_{x,y,z}`. O tempo relativo das amostras foi reconstruído pela frequência declarada de 50 Hz. Os participantes são representados pelos identificadores pseudônimos já presentes na base. [Registro no UCI Machine Learning Repository](https://doi.org/10.24432/C54S4K) · [Arquivo oficial](https://archive.ics.uci.edu/static/public/240/human+activity+recognition+using+smartphones.zip)

**Citação solicitada pelos autores.** Davide Anguita, Alessandro Ghio, Luca Oneto, Xavier Parra e Jorge L. Reyes-Ortiz. *A Public Domain Dataset for Human Activity Recognition Using Smartphones*. European Symposium on Artificial Neural Networks, Computational Intelligence and Machine Learning (ESANN), Bruges, 2013.

**Termos publicados.** O catálogo atual da UCI indica Creative Commons Attribution 4.0 International. O README histórico dentro do ZIP também solicita citação e contém uma restrição a uso comercial. Este repositório distribui derivados para demonstração de portfólio. Os créditos e as indicações das duas fontes ficam registrados aqui. Os nomes dos fabricantes identificam o aparelho do experimento original.
